# PKMSVV — PokéSurvivor Windows Offline

Bộ đóng gói và tùy biến **phi thương mại** dành cho phiên bản Windows của PokéSurvivor. Mã nguồn game được lấy từ [JPTER78/pokesurvivor](https://github.com/JPTER78/pokesurvivor), giữ nguyên ghi công và điều kiện sử dụng. Đây **không phải** bản phát hành chính thức của tác giả.

Tài liệu và quy trình build sẽ được bổ sung cùng mã desktop.
